# 🐉 Chinese Dragon Automaton

Final project for 3D Printing — a 3D printed automaton that reproduces the 
undulating motion of a Chinese dragon through a hand-cranked mechanism powered 
by phase-offset cams.

---

## 🎯 How It Works

The mechanism operates on the principle of **phase-offset cam transmission**. 
By rotating the hand crank, a central shaft drives multiple cams positioned 
at different angles along its length. Each cam actuates a vertical follower 
rod corresponding to a segment of the dragon's body.

The progressive offset between the cams causes the dragon's segments to rise 
and fall **sequentially rather than simultaneously**, creating the visual 
effect of a wave traveling from head to tail — the characteristic motion of 
Chinese dragons in traditional parades.

The faster the crank is rotated, the more dynamic the wave becomes along the 
body, mimicking the motion of a dragon "flying" through the air.

## 🧩 Main Components

| Component | Quantity | Role |
|-----------|----------|------|
| Hand crank | 1 | Manual input — the user rotates the crank to drive the mechanism |
| Main shaft | 1 | Supports the offset cams and transmits rotation from the crank |
| Offset cams | [4-6] | Convert rotation into vertical motion, each positioned at a different angle to create the wave effect |
| Vertical followers | [4-6] | Follow the cam profiles and transmit motion to the body segments |
| Dragon head | 1 | Decorative front piece — the first segment to move |
| Body segments | [3-5] | Intermediate pieces of the dragon that create the undulating effect |
| Dragon tail | 1 | Decorative end piece — the final segment of the wave |
| Base + side walls | 1 set | Support the shaft, guide the vertical followers, and form the mechanism's housing |
| Bearings / bushings for shaft | 2 | Allow smooth rotation of the main shaft within the side walls |
